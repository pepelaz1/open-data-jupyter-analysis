# Мини-исследование реальных открытых данных в Jupyter

Пример ответа на задачу с Kwork: загрузить настоящий CSV, проверить данные, посчитать показатели, сравнить две группы и сделать вывод с числами.

## Данные

- Оригинал: [Plotly datasets — gapminder2007.csv](https://github.com/plotly/datasets/blob/master/gapminder2007.csv).
- Дата получения: 18 ноября 2026 года.
- Локальная копия: [`data/gapminder2007.csv`](data/gapminder2007.csv), сохранена без изменений.
- Git blob SHA исходника и локальной копии совпадают: `044ac3968f68282739639b7d90d94d2ba39dfd93`.
- 142 строки: одна строка — одна страна в 2007 году. Есть категория `continent` и числовое поле `lifeExp`.

## Запуск

Откройте терминал в этой папке и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m notebook
```

Откройте `gapminder_analysis.ipynb` и выберите **Run All**. Ноутбук читает CSV по относительному пути, поэтому запускайте Jupyter из этой папки. Данные не перезаписываются.

## Проверенный результат

Средняя ожидаемая продолжительность жизни по странам Африки — 54,81 года (52 страны), Европы — 77,65 года (30 стран). Разница средних — 22,84 года. Это описание выборки за 2007 год, не оценка текущей ситуации и не доказательство причин различия.

Для проверки воспроизводимости: `python make_notebook.py` заново строит ноутбук из локального CSV и проверяет число строк, обязательные поля, пропуски и уникальность стран.
